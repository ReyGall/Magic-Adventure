A system-driven 3D action RPG focused on flexible magic, combat interactions, and player experimentation.

## Overview

This project is an experimental Unity game built around one core idea:

**Give the player a set of fundamental magical mechanics and let them discover how to combine them.**

Instead of relying on dozens of predefined spells, the game aims to build magic as a flexible system of parameters, forces, effects, and interactions.

The current prototype features a low-poly 3D environment, a placeholder mage character, and the foundations for a third-person combat system.

## Core Philosophy

* **System over content:** A small number of powerful mechanics should create many possible interactions.
* **Player experimentation:** Players should be able to discover unexpected uses for their abilities.
* **Modular architecture:** Magic, combat, characters, and effects should remain independent and reusable.
* **Simple foundations, complex results:** The goal is to create deep gameplay from relatively simple rules.
* **Prototype first:** Gameplay systems are developed before visual polish and large-scale content.

## Planned Features

* **Third-Person Combat:** Responsive movement, camera controls, targeting, and combat.
* **Lock-On System:** Optional target locking for more precise combat.
* **Dynamic Magic:** Spells built from configurable properties rather than hardcoded abilities.
* **Mana System:** Mana management instead of relying exclusively on traditional cooldowns.
* **Physical Interactions:** Magic capable of pushing, pulling, moving, and affecting objects in the environment.
* **Spell Combinations:** Different magical effects can interact with each other and produce new possibilities.
* **Enemy AI:** Enemies capable of reacting to the player's actions and magical effects.
* **Experimental Gameplay:** Tools and mechanics designed to encourage creative solutions.
